# 资源消耗服务器

这是一个Node.js服务器，实现每秒3KB的稳定资源消耗。

## 功能特点

1. 基础HTTP服务器，确保稳定运行且不会自动终止
2. 精确控制在每秒消耗3KB的速率
3. 资源消耗持续进行，中间无明显中断
4. 提供简单的状态监控接口，可查询当前资源消耗状态和累计消耗数据
5. 服务器运行稳定，不会出现内存泄漏或异常崩溃
6. 实现优雅关闭机制，能够在接收到终止信号时正确清理资源并停止运行

## 安装与运行

1. 安装依赖：
```bash
npm install
```

2. 启动服务器：
```bash
npm start
```

或者使用开发模式（需要安装nodemon）：
```bash
npm run dev
```

## API接口

- `GET /` - 主页，显示基本信息和导航链接
- `GET /status` - 查看资源消耗状态和累计消耗数据
- `GET /start` - 启动资源消耗
- `GET /stop` - 停止资源消耗
- `GET /cleanup` - 清理临时文件

## 资源消耗机制

服务器通过以下方式消耗资源：

1. 每秒创建3KB大小的临时文件，消耗磁盘空间
2. 执行简单的CPU密集型操作，消耗CPU资源
3. 定期清理临时文件，避免文件系统过载

## 优雅关闭

服务器监听以下信号并执行优雅关闭：
- SIGTERM
- SIGINT (Ctrl+C)

关闭时会：
1. 停止资源消耗
2. 清理所有临时文件
3. 退出进程
